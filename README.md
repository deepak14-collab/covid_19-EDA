# COVID-19 Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on COVID-19 datasets to analyze the spread, trends, and impact of the pandemic across different countries and regions.

The analysis includes:
- Data Cleaning
- Data Preprocessing
- Statistical Analysis
- Data Visualization
- Insight Generation

---

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📊 Key Analysis Performed
- Total confirmed cases analysis
- Death and recovery trend analysis
- Country-wise comparison
- Top affected countries visualization
- Time-series trend analysis
